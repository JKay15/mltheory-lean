## Hierarchical structure

- `MLTheory/Core/*`:Core objects and basic statements(prohibit `Prop := True` Placeholder).
- `MLTheory/Methods/*`:Method layer interface and reusable construct(prohibit `Prop := True` Placeholder).
- `MLTheory/Applications/*`:Application adaptation layer(Allow periodic space occupation).
- `MLTheory/Books/*`:Book chapter compatibility layer and re-export(Does not carry core definitions).

## Document system(SSOT)

- single source of truth:`/Users/xiongjiangkai/xjk_papers/MLTheory/docs/ssot/registry.json`
- field contract:`/Users/xiongjiangkai/xjk_papers/MLTheory/docs/ssot/schema.json`
- Derived document generation:`python3 tools/docs/sync_docs.py --write`

remove `registry.json` outside,`docs/*.md` and `docs/books/*.md` All are derived files,Do not directly correct text data manually.

`docs/meta/*.yaml` and `docs/_auto/*` used for vNext Incremental metadata and automated views for:
- `docs/meta/`:taxonomy/aliases/canon + optional backlog/ui(Manual maintenance,incremental information)
- `docs/_auto/`:generated by script(Machine view)

Derived markdown files are generated with `AUTO:*` blocks so script updates stay block-scoped.
